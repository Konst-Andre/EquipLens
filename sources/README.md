# sources/ — вихідні дані

Оригінали, з яких збираються `data/` і `media/` (корінь; після переїзду Р-7 — у теці сайту): xlsx, zip, фото. Не публікуються.
Якщо дані приватні — репо стає приватним цілком; у `docs/` потрапляє тільки зібране.

`fonts/` — оригінал шрифту тексту `Manrope[wght].ttf` (google/fonts:ofl/manrope, версія 4.505, 20.11.2026) і `OFL.txt`; з нього `tools/fonts.py build` ріже підмножину в `src/fonts/`. Chillax (ITF FFL v2.0) сюди не кладемо: файл у публічному репо ліцензія забороняє (`lens/DES-1_brief.md` рядок «Шрифти»).
